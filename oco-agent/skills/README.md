# Skills shared by every agent on the lab

Claude Code skills: procedures any session on the lab machine finds by itself when the work calls for them,
kept here once instead of in each agent's memory or each project's brief. They point to the words of
`oco-work` rather than repeating them. On the lab they are linked into `~/.claude/skills/`, so the version
in use is this clone's main.

- `lab-session-start` - the practices, signing your work, the inbox, looking before choosing
- `land-a-change` - branch first, change what you mean, check like CI, record, land, read main back
- `change-the-phone` - only through devlab, one change at a time, tests first, results file themselves
- `record-the-work` - where decisions, research, backlog, logs and the author's words go

A procedure done a second time by hand belongs here (or as a word of `oco-work`), not in the next brief.
